## 2. Active Skills & Design Directives

### A. `antigravity-design-expert` & Minimal Blue-Tinted Palette
* **Visual Direction:** Architectural minimalism, high-contrast monochrome with cool midnight slate and glacial blue undertones, spatial depth, weightless components. Zero logo color dependence (no heavy navy, gold, or saturated sky blue). Inspired by Linear, Vercel, Apple Pro, and Swiss typography craft.

    * `dark/bg-void`: `#05080E` (Deep spatial midnight void)

    * `dark/surface-glass`: `rgba(56, 189, 248, 0.04)` to `rgba(147, 197, 253, 0.07)` fill with 16–24px blur
    * `dark/border-hairline`: `rgba(147, 197, 253, 0.12)` (1px cold glacial specular edge)
    * `dark/action-primary`: `#FFFFFF` with `#0B0F17` text (Inverted White high-contrast button)

  * **Level 0 (Base):** Canvas / background `#0B0F19`.

  * **Level 3 (Modal / Overlay):** Translucent fill (`rgba(255,255,255,0.08)`), blur 32px, prominent border, high elevation shadow.

  * `3D-H1`: Hero interactive tech sphere / abstract data cluster (600x600 web, 340x340 mobile).

  * `3D-DEV`: Spatial device mockups for Products & Case Studies.
  * `3D-SYS`: 404 / 500 / Maintenance spatial artifact.
  * Every 3D zone must include fallback poster specifications for reduced motion / low-power mode.
* **Motion Tokens (`MOT`):**
  * `MOT-01`: Standard Reveal Up (`fade + 24px rise`, duration: 400ms, ease: `power2.out`).
  * `MOT-02`: Staggered Grid Reveal (stagger: 60ms).
  * `MOT-03`: Glass Card Lift & Tilt (hover lift 4px, 3D tilt, duration: 300ms).
  * `MOT-04`: Parallax Depth Scroll (max 2 Z-axis layers).
  * `MOT-05`: Trust Metric Counter (smooth number interpolation).
  * `MOT-06`: Continuous Marquee (pause on hover / reduced motion).
  * `MOT-07`: Modal / Drawer Spring Slide.
  * `MOT-08`: Sticky Bar Reveal (trigger after hero viewport scroll).

### B. `balise-ux-writing`
* **4 Quality Standards:** Purposeful, Concise, Conversational, Clear.
* **Tone:** Modern Standard Arabic (فصحى معاصرة), confident, dignified, outcome-focused, zero hype, zero slang, no generic placeholder text (no Lorem Ipsum).
* **CTA Consistency:** 
  * Primary: "اطلب عرض سعر" (`/quote`)
  * Secondary: "احجز مكالمة استشارية" (`/book`)
  * Instant: "تواصل عبر واتساب" (WhatsApp)
* **Form Microcopy:** Actionable, transparent validation feedback, empathetic and non-blaming error states.

### C. `component-to-figma-prototype`
* **Purpose:** Translates pasted component code (React, HTML5 Canvas, CSS animations, physics springs) into interactive Figma prototypes using component sets, variants, variables, and Smart Animate interactions.
* **Golden Rules:** Treats pasted code as a behavioral SPEC (no code run/shipped). Maps spring physics (`SPRING`, damping, bounce), per-element/per-character states, and hover/click triggers directly to Figma interactions. Preserves Arabic cursive typography integrity.
